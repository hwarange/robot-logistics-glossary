# 🤖 물류 로봇 시뮬레이션 용어사전

AIoT 로봇 물류 시뮬레이션 프로젝트(쿠팡식 물류센터, NVIDIA Isaac Sim)를 위한 도메인 용어 학습 사이트입니다.

## 기능

- **11개 카테고리, 200여 개 용어** — 물류센터, 물류 로봇, ROS/로봇 기본, 시뮬레이션, NVIDIA 생태계, 강화학습, 최신 로봇 AI, 최적화, 물류 최적화, 경로 탐색(MAPF), 멀티에이전트
- **검색 & 카테고리 필터** — 영문/한글 용어, 정의 본문까지 검색
- **출처 링크** — 모든 용어에 공식 문서 · 위키피디아 · 논문 출처 표기
- **플래시카드 학습 모드** — 카드 뒤집기로 암기 학습 (Space: 뒤집기, →: 알아요, ←: 몰라요)
- **암기 진도 저장** — 브라우저 localStorage에 암기 완료 표시 저장
- **다크 모드 지원**

## 구조

```
index.html      # 페이지 뼈대
styles.css      # 스타일 (라이트/다크 테마)
app.js          # 검색·필터·플래시카드 로직
data.js         # 병합된 용어 데이터 (build.ps1 로 생성)
data/*.json     # 카테고리별 원본 용어 데이터
build.ps1       # data/*.json → data.js 병합 스크립트
```

## 용어 수정/추가 방법

1. `data/<카테고리>.json` 에서 용어를 수정하거나 추가
2. `powershell -File build.ps1` 실행해 `data.js` 재생성
3. 커밋 & push → GitHub Pages 자동 반영
